# 醍醐 V1.0 软著鉴别材料 — 使用说明

本目录已生成两类鉴别材料草稿，按中国版权保护中心「一般交存」要求整理后上传 PDF 即可。

## 已生成文件

| 文件 | 用途 |
|------|------|
| `醍醐_V1.0_软件说明书.md` | **文档鉴别材料**正文 |
| `醍醐_V1.0_程序鉴别材料.txt` | **程序鉴别材料**（前 30 页 + 后 30 页源码） |
| `醍醐_V1.0_源文件清单.txt` | 交存源码文件列表（备查，一般不必上传） |
| `gen_program_deposit.py` | 重新生成程序鉴别材料的脚本 |

## 一、文档鉴别材料 → PDF

1. 用 Word / Typora / VS Code 打开 `醍醐_V1.0_软件说明书.md`。
2. 复制到 Word 后建议：
   - 页眉：`醍醐 V1.0 软件说明书`
   - 字体：宋体/黑体，小四或五号
   - 页脚：页码
3. 导出/打印为 PDF：`醍醐_V1.0_文档鉴别材料.pdf`
4. 上传：
   - 总页数 **&lt; 60**：上传**全文**
   - 总页数 **≥ 60**：上传**前连续 30 页 + 后连续 30 页**

## 二、程序鉴别材料 → PDF

1. 用 Word 打开 `醍醐_V1.0_程序鉴别材料.txt`（UTF-8）。
2. 建议版式：
   - 等宽字体（Consolas / 宋体）
   - 字号小五或六号，保证**每页不少于约 50 行**
   - 页眉已在文本中按页写了「醍醐 V1.0 源程序 第 x 页」；也可用 Word 页眉再写软件名与版本
3. 导出 PDF：`醍醐_V1.0_程序鉴别材料.pdf`
4. 系统选项选 **一般交存**，上传该 PDF。

## 三、重新生成源码交存稿

在项目根目录执行：

```powershell
python docs\ruanzhu\gen_program_deposit.py
```

## 四、注意

- 申请表中的**软件全称、版本号**须与页眉一致（当前：`醍醐` / `V1.0`）。
- 不要把 `.env`、证书、真实 API Key 打进交存材料；脚本已对部分密钥字面量做简单脱敏。
- 「源程序量」建议与交存范围一致：仅 App 填约 **24000** 行。
