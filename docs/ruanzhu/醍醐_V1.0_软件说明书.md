## 第 1 章 概述

### 1.1 软件简介

「醍醐」是一款面向个人效率与知识管理的移动应用软件。软件以笔记记录为核心，融合备忘、日常（日程）、文章阅读与智能辅助编辑等能力，帮助用户完成日常记录、待办提醒、日程安排与内容阅读。

软件采用 Flutter 跨端技术实现 Android 客户端，结合本地数据库与云端服务，支持登录同步、富文本编辑、语音输入、附图识图及对话式 AI 改稿等功能。

### 1.2 适用对象

- 需要记录笔记、备忘与日程的个人用户
- 希望结合智能助手快速起草、润色文稿的用户
- 需要浏览与管理阅读内容的用户

### 1.3 运行环境

| 类别 | 要求 |
|------|------|
| 操作系统 | Android 8.0 及以上 |
| 硬件 | ARM64 智能手机，建议内存 4GB 及以上 |
| 网络 | 登录、同步、AI、识图等功能需可访问互联网 |
| 权限 | 按需申请麦克风、相册、通知、定位等系统权限 |

### 1.4 软件主要特点

1. **多形态笔记**：支持笔记、备忘、日常、文章、谏言等多种内容形态。
2. **富文本编辑**：正文支持标题层级、加粗、斜体、列表、对齐等格式。
3. **智能改稿**：笔记编辑页内置 AI 助手，可改标题、写正文、追加、局部增删改及改类型。
4. **语音与识图**：支持听写输入与附图理解，辅助写入笔记。
5. **本地与云端协同**：本地可离线查阅已有数据；登录后可与云端同步。
6. **模块化导航**：底部导航覆盖笔记、备忘、日常、阅读、其他等入口。

## 第 2 章 安装与启动

### 2.1 安装

1. 获取本软件 Android 安装包（APK）。
2. 在设备上允许安装未知来源应用（如系统要求）。
3. 打开安装包，按提示完成安装。
4. 安装完成后，主屏幕出现「醍醐」图标。

### 2.2 首次启动

1. 点击「醍醐」图标启动应用。
2. 应用完成初始化（本地数据库、必要配置）。
3. 未登录时，默认可进入阅读等访客可用模块；笔记/备忘/日常等需登录后完整使用。
4. 登录后默认进入「笔记」模块。

### 2.3 升级与卸载

- **升级**：安装新版本 APK 覆盖安装，或按应用内更新提示操作。
- **卸载**：在系统应用管理中卸载「醍醐」。卸载将删除本机应用数据，云端账号数据不受本机卸载直接影响。

## 第 3 章 账号与登录

### 3.1 注册 / 登录

1. 进入登录页。
2. 按提示输入账号与密码（或以系统提供的登录方式完成认证）。
3. 登录成功后进入主界面。
4. 登录失败时，界面给出可读错误提示（如账号或密码不正确、网络异常等）。

### 3.2 退出登录

1. 进入「其他 / 我的」相关设置页。
2. 选择退出登录。
3. 退出后回到访客可用状态，笔记等私有数据入口将提示登录。

### 3.3 账号安全说明

- 请妥善保管账号与密码。
- 不要在公共设备上勾选长期免密（如有该类选项）。
- 云端通信使用 HTTPS 等安全通道（以实际部署为准）。

## 第 5 章 笔记模块

### 5.1 笔记列表

1. 进入「笔记」。
2. 查看已有笔记列表。
3. 点击条目进入编辑；通过新建按钮（如 FAB）创建新笔记。
4. 支持下拉刷新与分页加载（如已实现）。

### 5.2 新建笔记

1. 点击新建。
2. 进入笔记编辑页，默认类型可为「笔记」。
3. 填写标题（可选，保存时可根据正文自动建议标题）。
4. 编辑正文富文本。
5. 点击「保存/添加」完成落库。

### 5.3 编辑与离开保护

1. 修改标题、正文或类型后，内容处于未保存（脏）状态。
2. 点击保存成功后，脏状态清除。
3. 若未保存即返回或切换模块，系统提示是否保存：
   - 选择「是」：先保存再离开
   - 选择「否」：放弃修改离开
   - 选择「返回」：继续留在编辑页

### 5.4 笔记类型

编辑页可切换类型：

| 类型 | 说明 |
|------|------|
| 笔记 | 通用记录 |
| 备忘 | 备忘事项，保存后进入备忘列表 |
| 日常 | 日程安排，需填写时间等 |
| 文章 | 面向阅读发布的内容 |
| 谏言 | 管理员可用的推荐类内容（权限受限） |

切换类型后，界面展示对应选项（如日常时间、重复规则等）。

### 5.5 富文本工具栏

正文编辑器提供常见格式，例如：

- 标题层级（H1/H2/H3）
- 字号
- 加粗、斜体
- 有序/无序列表
- 对齐
- 清除格式

## 第 7 章 日常（日程）模块

### 7.1 日历与列表

1. 进入「日常」。
2. 查看日历与当日/所选日安排。
3. 可通过侧栏月历快速跳转日期。
4. 点击已有日常进入编辑；可按时间点创建新日常。

1. 选择或默认带入日常时间。

3. 设置提醒偏移（如提前 5 分钟、15 分钟，或不提醒）。

5. 每周重复时可选择星期；可设置结束方式（永不 / 直到某日 / 重复次数）。
6. 保存后出现在对应日期安排中。

### 7.3 提醒

- 日常可配置提醒时间。
- 需授予通知权限后方可正常收到提醒。
- 可在提醒相关页面查看与管理提醒设置。

## 第 9 章 笔记 AI 助手

### 9.1 打开 AI

1. 进入任意笔记编辑页。
2. 打开右侧或下方「笔记 AI」面板。
3. 可展开/收起；可开新对话（会话按当前草稿隔离）。

### 9.2 常见指令示例

| 用户说法 | 预期效果 |
|----------|----------|
| 帮我写一个「明天记得打卡」的备忘 | 切到备忘类型并写入标题/正文 |
| 帮我将类型改成文章 | 更新笔记类型为文章 |
| 帮我写一篇关于……的文章 | 写标题与完整正文 |
| 最后加一句…… | 在文末追加，不覆盖全文 |
| 在「今天你好吗」前面写「……」，后面写「……」 | 按原文片段局部插入 |

### 9.3 AI 工作状态

- 处理中显示「思考中…」。
- 处理期间锁定编辑器，避免与 AI 改写冲突。
- 完成后解锁，并在对话中给出简短结果提示（如「已写入正文」「已在指定句后插入」）。

### 9.4 AI 能力边界

- AI 只改当前这篇草稿，不批量改其他笔记。
- 局部修改应保留原文其他部分；追加不应整篇覆盖。
- 无有效工具调用时，不应仅用口头「已写入」冒充成功。
- 谏言类型等能力可能受管理员权限限制。

### 9.5 语音与附图

1. **语音**：按住/点击麦克风听写，识别文本进入输入框或插入正文。
2. **附图**：选择图片后，系统识图并将理解结果用于改稿提示。
3. 使用前需授予相应权限。

## 第 11 章 软件结构说明（设计概要）

### 11.1 逻辑结构

软件客户端主要分为以下层次：

1. **表现层（UI）**：页面、导航、编辑器、列表与对话框。
2. **状态层**：应用状态管理（如 AppStore），协调数据加载与刷新。
3. **领域层**：笔记模型、标题建议、重复规则、AI 文本处理、片段编辑等。
4. **数据层**：本地数据库（SQLite）、偏好设置、缓存。
5. **服务层**：认证、同步、提醒、媒体上传、LLM/ASR/OCR 等外部能力。

### 11.2 主要目录说明（源程序）

| 目录 | 说明 |
|------|------|
| lib/main.dart | 应用入口与根组件 |
| lib/ui/ | 界面页面与组件 |
| lib/domain/ | 领域模型与业务规则 |
| lib/data/ | 本地数据库访问 |
| lib/state/ | 全局状态 |
| lib/auth/ | 登录认证 |
| lib/agent/ | 智能助手、语音、识图、模型调用 |
| lib/sync/ | 同步 |
| lib/reminders/ | 提醒 |
| lib/media/ | 媒体处理与上传 |
| lib/social/ | 社交/阅读相关接口模型 |
| lib/share/ | 分享 |
| lib/config/ | 编译期配置读取 |

### 11.3 关键业务流程

#### （1）保存笔记

1. 用户点击保存。
2. 校验必填项（如日常标题、时间）。
3. 组装标题、正文（Quill Delta）、类型与日程字段。
4. 写入本地库；必要时更新上架状态。
5. 刷新列表；更新未保存基线。

#### （2）AI 改稿

1. 用户输入自然语言指令。
2. 客户端附带当前标题、选项、正文上下文请求模型。
3. 模型返回工具调用（改标题/替换正文/追加/局部编辑/改选项等）。
4. 客户端顺序应用工具，更新编辑器。
5. 对多步局部插入进行校验与补全，保证用户要求的文字落入正文。

#### （3）登录后同步

1. 用户登录成功。
2. 启动引导加载（bootstrap）。
3. 按同步策略拉取/推送变更。
4. 刷新各模块列表。

### 11.4 数据存储概要

- **本地**：笔记正文以富文本 Delta JSON 存储；元数据含类型、时间、重复、提醒等。
- **云端**：登录用户笔记与账号关联存储（具体表结构以实现为准）。
- **会话**：笔记 AI 对话按草稿隔离保存，避免串话。

### 11.5 安全与隐私概要

- 密钥类配置通过编译期注入或服务端代理，避免硬编码明文密钥进仓。
- 上传与 API 调用走加密传输。
- 权限按功能最小必要申请。

## 第 13 章 操作示例

### 示例 A：写一篇备忘

1. 打开 App 并登录。
2. 进入笔记编辑（或备忘新建）。
3. 在 AI 面板输入：`帮我写一个「明天记得打卡」的备忘`。
4. 确认类型变为备忘，标题与正文已生成。
5. 点击添加/保存。
6. 在备忘列表中看到新条目。

### 示例 B：局部修改正文

1. 正文已有：`今天你好吗`。
2. 对 AI 说：在「今天你好吗」前面写「记得我们的过去吗？」，再在后面写「我们要憧憬未来呀！」与「未来什么样？」。
3. 确认正文变为包含上述全部插入内容。
4. 保存。

### 示例 C：安排日常

1. 进入日常，选择日期时间。
2. 填写标题「周会」。
3. 设置每周重复、提醒提前 15 分钟。
4. 保存后在日历中查看。

### 示例 D：发布文章

1. 编辑页选择「文章」。
2. 填写标题与正文。
3. 保存/发布。
4. 在阅读「我的」中查看。

## 第 14 章 常见问题

**Q1：保存后仍提示是否保存？**  
请确认已点击保存且成功提示出现；若仍提示，可再保存一次后离开。新版本已优化脏状态基线。

**Q2：AI 说已写入但正文没有？**  
可换更明确的说法重试，例如指定「写入正文」或「在某句后面写……」。

**Q3：收不到日常提醒？**  
检查系统通知权限、电池优化白名单及提醒开关。

**Q4：访客能用哪些功能？**  
一般可浏览阅读公开内容；笔记/备忘/日常需登录。

**Q5：卸载后数据还在吗？**  
本机数据删除；已同步到云端的账号数据可在重新登录后按同步策略恢复。

3. 多处「前面写/后面写」应按顺序全部完成。
